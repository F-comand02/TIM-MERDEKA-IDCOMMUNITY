## 🇮🇩 Tentang Project

**MERDEKA COMMUNITY** adalah sebuah platform digital yang dibuat dalam rangka memperingati **Hari Kemerdekaan Republik Indonesia** sekaligus mengikuti kompetisi website yang diselenggarakan oleh **ID Community**.

Project ini membawa gagasan bahwa semangat kemerdekaan tidak seharusnya hanya diwujudkan melalui perayaan, tetapi juga melalui **aksi nyata yang dapat dilakukan oleh masyarakat di lingkungan sekitar.**

Website ini dirancang untuk menjadi sebuah ruang digital yang memungkinkan pengguna untuk:

* 🇮🇩 Mengenal kembali semangat kemerdekaan.
* 🤝 Mengikuti dan melakukan aksi positif.
* 📸 Mengirimkan dokumentasi aksi.
* 🏆 Mengumpulkan poin melalui kontribusi.
* 📊 Melihat perkembangan kontribusi secara keseluruhan.
* 🗺️ Mengetahui persebaran aksi yang dilakukan.

> **Kemerdekaan bukan hanya tentang apa yang telah diperjuangkan oleh para pahlawan, tetapi juga tentang apa yang kita lakukan untuk Indonesia hari ini.**

---

# 🎯 Latar Belakang

Kemerdekaan Indonesia merupakan sebuah pencapaian besar yang lahir dari perjuangan dan pengorbanan.

Namun, seiring perkembangan teknologi dan perubahan generasi, bentuk kontribusi terhadap bangsa juga dapat berkembang.

Generasi saat ini memiliki cara baru untuk menunjukkan rasa peduli terhadap lingkungan dan masyarakat.

Melalui teknologi digital, kami mencoba menghadirkan sebuah platform yang mengubah semangat:

```text
🇮🇩 Semangat Kemerdekaan
          ↓
      Aksi Nyata
          ↓
     Dokumentasi
          ↓
       Validasi
          ↓
        Poin
          ↓
    Dampak Bersama
```

Dengan konsep tersebut, website ini tidak hanya menjadi media informasi, tetapi juga menjadi sarana untuk mendorong pengguna agar **bergerak dan memberikan kontribusi nyata.**

---

# 💡 Konsep Utama

Project ini dibangun dengan konsep:

## **"Dari Semangat Menjadi Aksi."**

Pengguna tidak hanya membaca informasi mengenai kemerdekaan, tetapi diajak untuk mengambil bagian melalui aksi positif.

Contoh aksi yang dapat dilakukan:

* 🧹 Membersihkan lingkungan.
* 🌱 Menanam pohon.
* ♻️ Mengurangi sampah.
* 🤝 Membantu masyarakat sekitar.
* 📚 Berbagi ilmu.
* ❤️ Melakukan kegiatan sosial.
* 🇮🇩 Berbagai aksi positif lainnya.

Setiap aksi dapat didokumentasikan melalui foto dan dikirimkan ke sistem untuk diproses.

# ✨ Fitur Utama

## 👤 1. User System

Pengguna dapat membuat akun dan menggunakan platform untuk mengikuti berbagai aktivitas.

Fitur meliputi:

* Registrasi
* Login
* Logout
* Session management
* Profile pengguna
* Riwayat aktivitas

---

## 📸 2. Submit Aksi

Pengguna dapat mengirimkan aksi yang telah dilakukan melalui website.

Data yang dikirimkan dapat meliputi:

```text
Nama Aksi
Deskripsi
Kategori
Lokasi
Tanggal
Foto Bukti
```

Setelah dikirimkan, aksi akan masuk ke sistem untuk proses validasi.

---

## 🔍 3. Validasi Aksi

Untuk menjaga kualitas data, setiap aksi yang dikirimkan pengguna akan melalui proses verifikasi oleh administrator.

Alur:

```text
User
 │
 │ Submit Aksi
 ↓
Pending
 │
 ↓
Admin Review
 │
 ├───────────────┐
 ↓               ↓
Approved       Rejected
 │
 ↓
Point Added
```

Dengan sistem ini, poin tidak langsung diberikan hanya karena pengguna mengirimkan sebuah aksi.

---

# 🛡️ 4. Admin Dashboard

Administrator memiliki dashboard khusus untuk mengelola aktivitas platform.

Admin dapat:

* Melihat aksi yang masuk.
* Membuka detail aksi.
* Melihat foto bukti.
* Memeriksa informasi pengguna.
* Menyetujui aksi.
* Menolak aksi.
* Mengelola data pengguna.
* Memantau statistik aktivitas.

Dashboard menjadi bagian penting untuk menjaga integritas data yang terdapat di dalam platform.

---

# 🏆 5. Point & Contribution System

Setiap aksi yang telah diverifikasi dapat memberikan **poin kontribusi** kepada pengguna.

Contoh konsep:

```text
Aksi berhasil diverifikasi
          ↓
      + Poin
          ↓
Total kontribusi pengguna bertambah
```

Poin tersebut dapat digunakan untuk membangun sistem:

* 🏅 Ranking
* 🥇 Leaderboard
* 📊 Statistik kontribusi
* 🎖️ Achievement
* 🌟 Level pengguna

---

# 🗺️ 7. Location & Map

# 🚀 Development & Installation

## 1. Clone Repository

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Masuk ke folder project:

```bash
cd REPOSITORY
```

---

## 2. Jalankan Laragon

Pastikan:

* Apache aktif.
* MySQL aktif.

Kemudian letakkan project pada folder:

```text
C:\laragon\www\
```

Contoh:

```text
C:\laragon\www\nama-project
```

---

## 3. Setup Database

Buat database baru melalui **phpMyAdmin** atau database manager yang tersedia.

Contoh:

```text
nama_database
```

Kemudian import file SQL apabila tersedia:

```text
database/
└── database.sql
```

---

## 4. Konfigurasi Database

Sesuaikan konfigurasi pada:

```text
config/database.php
```

Contoh:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "nama_database";
```

---

## 5. Jalankan Project

Jika menggunakan Laragon, project dapat diakses melalui:

```text
http://localhost/nama-project
```

Atau menggunakan virtual host Laragon:

```text
http://nama-project.test
```
